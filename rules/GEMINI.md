# Always-On Orchestration Rule (antigravity-xteam)

For any coding, debugging, refactoring, architecture, or multi-step task, automatically activate and follow the `antigravity-xteam` skill without waiting for the user to mention it:
- Enforce `medium` or `low` thinking modes (never `high`/`xhigh` unless explicitly requested).
- Run `build`, `typecheck`, `lint`, and tests before invoking any LLM reviewer.
- Keep routine/standard work on short-window models (`Neon`, `Hydrogen`, `Flash`) and reserve scarce pools (`Claude`, `GPT`) for `xteam audit` or high-risk diffs (max 1 batched call/task).
- Honor `xteam lean` (zero `Claude`/`GPT` usage) and `xteam audit` (mandatory batched diff review).
